# Outreach (vertical slice scope)

Full outreach engine (campaigns, sequences, suppression list, email sending) is
deferred to a later phase (spec sections 27-31). What exists today:

## What's implemented

- `OutreachDraft` model — one draft per business, generated by AI from the
  business's actual collected facts + classified opportunity (never generic).
- `POST /api/businesses/{id}/analyze` generates the draft as part of the pipeline
  (skipped when the opportunity is `IGNORE` — spec section 62: don't waste
  outreach effort on businesses with no real opportunity).
- `GET /api/businesses/{id}/outreach-draft` — review the draft.
- `POST /api/businesses/{id}/outreach-draft/approve` — the human-approval gate
  (spec section 29). This only flips `approved: true`; nothing sends.

## What's deliberately NOT implemented yet

- No email sending, no SMTP/Google Workspace integration.
- No campaigns, recipients, or follow-up sequences.
- No suppression/do-not-contact list.
- No unsubscribe handling.

None of this exists because sending real outreach requires the compliance
groundwork (CAN-SPAM/GDPR/CASL handling, suppression list, bounce handling) to
be in place *first* — building send capability before that groundwork would
violate spec sections 28-31. Do not wire up an SMTP client against this draft
model without adding suppression + opt-out handling at the same time.
